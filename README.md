# 🧮 Calculator

A simple and responsive Calculator built using HTML, CSS, and JavaScript. This project performs basic arithmetic operations with a clean and user-friendly interface.

## 🚀 Live Demo
https://faisalkhan-fk.github.io/Calculator/

## ✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🧹 Clear (AC)
- ⌫ Delete (DEL)
- 📱 Responsive Design
- ⚡ Fast Calculations

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```
Calculator/
│── index.html
│── style.css
│── script.js
```

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/faisalkhan-fk/Calculator.git
```

2. Open the project folder.

3. Run `index.html` in your browser.
